# Backend - SenseControl

Ainda não implementado. Será a API REST + WebSocket em Node.js/TypeScript/Express, responsável por: assinar as leituras publicadas via MQTT, validá-las e persisti-las no banco (PostgreSQL), aplicar as regras de detecção de desperdício e expor os dados para o frontend.

Chega na **Etapa 2** (cadastros e leituras) e é expandido nas etapas seguintes (autenticação, detecção de desperdício, recomendações, Swagger, testes). Veja `docs/ROADMAP.md` na raiz do projeto para o plano completo, e `docs/ARQUITETURA.md` / `docs/DECISOES_DE_TECNOLOGIA.md` para a justificativa da escolha tecnológica.
